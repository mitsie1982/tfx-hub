# TFX Hub Orchestration Integrations

This folder contains scaffolding for production-grade orchestration using TFX with Airflow, Vertex Pipelines, and MLMD (ML Metadata).

## Structure

- `tfx_airflow_pipeline.py` — TFX pipeline definition for Airflow
- `tfx_vertex_pipeline.py` — TFX pipeline definition for Vertex Pipelines
- `mlmd_setup.py` — MLMD (metadata store) integration stub

## Usage

- See each file for integration instructions and requirements.
- These are scaffolds: fill in your pipeline components and environment details as needed.
