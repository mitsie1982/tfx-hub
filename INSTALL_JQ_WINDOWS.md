# Windows jq installation instructions
# 1. Download jq.exe from the official site:
#    https://github.com/stedolan/jq/releases/latest
#    (Choose jq-win64.exe for 64-bit Windows)
# 2. Rename the downloaded file to jq.exe
# 3. Place jq.exe in a directory included in your PATH (e.g., C:\Windows or C:\Windows\System32)
# 4. Verify installation by running: jq --version

# For PowerShell, you can use this command to download and install jq to the current directory:
# Invoke-WebRequest -Uri "https://github.com/stedolan/jq/releases/latest/download/jq-win64.exe" -OutFile "jq.exe"
# Then add the current directory to your PATH or move jq.exe to a directory already in your PATH.

# After installing jq, re-run your demo sequence.
