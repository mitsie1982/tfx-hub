# MDM Enrollment Guidance (AWS)

- Use AWS SSO or IAM Identity Center with device posture checks.
- Integrate with third-party MDM (e.g., Microsoft Intune, Jamf, MobileIron) for device compliance.
- Enforce device compliance via SAML/SSO policies and conditional access.
- Example: Require device to be registered and compliant before granting access to AWS Console or CLI.
- Reference: https://docs.aws.amazon.com/singlesignon/latest/userguide/device-trust.html
