# SLA Monitoring Guide

- Use Azure Monitor, Application Insights, or New Relic for uptime and latency tracking.
- Set up alert rules for error rates, latency, and downtime.
- Integrate with PagerDuty/Opsgenie for on-call escalation.
- Document SLAs (e.g., 99.9% uptime, <1s API latency) and review monthly.
