# Onboarding Guide: Professionals

Welcome to TFX Hub! This guide will help you onboard as a service professional.

## Steps

1. Register via WhatsApp (follow the prompts).
2. Complete all onboarding stages (name, trade, experience, location, credentials).
3. Upload portfolio images and verify credentials (NHBRC, CIDB, etc.).
4. Start accepting jobs and build your reputation.
