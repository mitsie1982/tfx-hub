# TFSSA Demo Presenter Script

This script is the shortest reliable walkthrough for the live contractor and customer browser demos.

## Contractor Demo

1. Open the Contractor Desktop shortcut and wait for the page to show `Live Session Active`.
2. Point out `TFSSA Live Demo Scope` and `Fields Verified Live` to establish which fields are live-backed and which changes were already verified.
3. In `WhatsApp Subscription`, change the mobile number and submit it.
4. In `Matched Leads`, open a lead detail.
5. In `Express Interest`, send interest for the selected lead.
6. In `Submit Quote`, change all three editable fields:
   - Amount
   - Timeline
   - Note
7. Use `Review Quote`, show the edited values on `Confirm Quote`, then confirm it.
8. In `Send Homeowner Message`, change the message body, preview it, then confirm it.
9. Close by pointing to `Lead History` as the running record of the live workflow.

## Customer Demo

1. Open the Customer Desktop shortcut and wait for the page to show `Live Session Active`.
2. Point out `TFSSA Live Demo Scope` and `Fields Verified Live`.
3. Open a professional profile from `Professional Directory`.
4. Use `Shortlist Professional` to add the professional, show the visible shortlisted state, then remove it again.
5. In `Submit Job Request`, change all editable request fields:
   - Title
   - Trade
   - Location
   - Budget
   - Urgency
   - Description
6. Use `Review Request` to show the edited values on `Review Job Request`.
7. Confirm the request submission.
