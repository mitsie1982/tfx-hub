# DEPRECATION_LOG.md

## CCMS/AMMS Naming Migration

- All code and DB references to 'Contractor' and 'Association' are being migrated to 'CCMS' and 'AMMS'.
- Legacy values are normalized server-side for a 30–90 day deprecation window.
- Telemetry and monitoring are in place to track any legacy usage.
- Stakeholders will be notified via release notes and direct communication.
